# Web UI 字型

Noto Sans TC variable font copied from the existing sibling night-parade project (Google Noto, SIL OFL 1.1; see OFL.txt). `NotoSansTC-Regular.ttf` is a static weight-400 instance generated using fontTools.varLib.instancer, with updated font names. The original variable font defaults to weight 100 and is excluded from Web exports. Desktop continues to use its existing theme font.
